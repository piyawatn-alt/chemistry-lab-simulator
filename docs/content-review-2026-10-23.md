# บันทึกตรวจเนื้อหา ChemLab RX — 23 ตุลาคม 2026

## ขอบเขตและหลักฐาน

ตรวจข้อมูลปัจจุบันทั้ง 24 บทความ ภาพประกอบที่ผูกกับบทความ เครื่องมือโครงสร้างโมเลกุล และการทดลองจำลอง 7 แบบ โดยอ่านความสอดคล้องของนิยาม สูตร หน่วย เงื่อนไข และตัวอย่างคำนวณ เพิ่มการทดสอบการอนุรักษ์อะตอม/ประจุ และตรวจโครงสร้างตัวอย่างด้วย RDKit.js 2026.09.1

**นี่เป็นการตรวจความสอดคล้องและคำนวณซ้ำของข้อมูลในโครงการ ไม่ใช่การยืนยันจากการเปิดตำราออนไลน์ล่าสุดทุกบรรทัด** การเปิด OpenStax จากสภาพแวดล้อมนี้ถูกปฏิเสธด้วย `Tunnel connection failed: 403 Forbidden` จึงยังไม่ยืนยันสถานะลิงก์และข้อความล่าสุดของหน้าอ้างอิง ลิงก์ระดับบทถูกเพิ่มเพื่อให้ตรวจเทียบต่อได้ ส่วนสูตรโมเลกุล เวเลนซ์ การเชื่อมต่อ ตัวอย่างตัวเลข และผลจำลองที่ระบุด้านล่างตรวจได้ภายในสภาพแวดล้อมนี้

## จุดที่พบและแก้

1. ตารางหมู่ฟังก์ชันเดิมมี 8 กลุ่ม แต่ภาพโต้ตอบมีเพียง 4 กลุ่ม ขาดอีเทอร์และแฮโลแอลเคนจากตาราง และขาดภาพของหลายกลุ่มที่กล่าวถึงในเนื้อหา
2. เพิ่มตารางหมู่หลัก 10 กลุ่ม และภาพโต้ตอบครบทั้ง 10 กลุ่ม พร้อมตัวอย่างพันธะ/โครงสร้าง 3 แบบและหมู่เพิ่มเติม 2 แบบ รวม 15 โครงสร้าง แยกประเภทชัดเจน ไม่อ้างว่าเป็นหมู่ฟังก์ชันทุกชนิดในเคมีอินทรีย์
3. ระบุรูปแบบเอมีนและเอไมด์ที่แทนที่บน N หลายระดับ แยกความสามารถให้/รับพันธะไฮโดรเจน โดยเฉพาะเอมีนตติยภูมิและ N ของเอไมด์
4. แยกฟีนอลออกจากแอลกอฮอล์ คาร์บอนิลออกจากคีโตน เอสเทอร์ออกจากอีเทอร์ และ C≡C ออกจาก C≡N รวมข้อยกเว้น R = H ที่คาร์บอนิลในสารบางชนิด
5. แก้คำอธิบาย HCl–NaOH ที่เรียกรวมว่า “กรดและเบสหนึ่งโปรตอน” เป็นการนับโมล H⁺ และ OH⁻ ตามหน่วยสูตรและสมการที่ดุล
6. เพิ่มข้อควรระวัง mol/L กับ mol/kg, ppm กับ mg/L, STP ที่ 1 atm กับ 1 bar, ขอบเขต pH 0–14, เกลือไฮโดรไลซ์, Ksp, ข้อยกเว้นการจัดอิเล็กตรอน และชนิดพอลิเมอร์
7. ระบุว่ารหัสวิชา/ลำดับชั้นเป็นการจัดกลุ่มของคลังนี้ ไม่ใช่การรับรองว่าตรงกับทุกโรงเรียนหรือครอบคลุมผลการเรียนรู้ทุกข้อ
8. ชี้แจงว่าภาพโครงสร้างสารยาสร้างจากข้อมูลโครงสร้างด้วย RDKit ไม่ใช่ภาพที่คัดลอกจาก PubChem และภาพหมู่ฟังก์ชัน 4 แผงเป็นเพียงตัวอย่างย่อย

## ตรวจซ้ำ

- `npm run groups:generate` ตรวจ SMILES/SMARTS และสูตรของตัวอย่างทั้ง15ด้วย RDKit พร้อมสร้างข้อมูลภาพ11แบบใหม่ ไม่โหลด RDKit บนเบราว์เซอร์
- `npm test` ตรวจกราฟโมเลกุลทั้ง15 สมการอนุรักษ์อะตอม/ประจุ ตัวอย่างตัวเลข การเชื่อมรายการเนื้อหา และโมเดลการทดลอง
- `npm run test:molecules` กดภาพครบ15ชนิด เปิดH เน้นหมู่ คลิกพันธะสาม/วงอะโรมาติก ใช้คีย์บอร์ด และตรวจมือถือ
- `npm run test:content` เปิด24บทความ ตรวจภาพ ตัวเลขอนุภาค ไฮไลต์ ตาราง และรูปแบบมือถือ
- `npm run test:experiments`, `npm run test:flame-test` ตรวจการทดลองทั้ง7แบบ
- `npm run test:smoke` ตรวจการค้นหา เมนู ตัวกรอง และบันทึกบทความ
- `npm run build` ตรวจบิลด์และชนิดข้อมูลสำหรับเผยแพร่

การทดสอบเหล่านี้ตรวจประเด็นที่ระบุ ไม่รับรองความถูกต้องของความรู้เคมีทุกด้าน หรือความครบของหลักสูตรทั้งประเทศ การตรวจเทียบตำราหรือหลักสูตรฉบับปัจจุบันแบบอิสระยังต้องแยกจากการทดสอบโปรแกรมและการตรวจโครงสร้างด้วยเครื่องมือ
