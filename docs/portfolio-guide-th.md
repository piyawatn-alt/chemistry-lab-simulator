# ChemLab RX — แนวทางนำโครงงานไปเล่าในพอร์ตเภสัช

ชื่อโครงงานที่ใช้ได้: **ChemLab RX: แหล่งเรียนรู้เคมีเชื่อมเภสัชศาสตร์ผ่านแบบจำลองและบันทึกการเรียนรู้ด้วยตนเอง**

เว็บไซต์: https://chemistry-lab-simulator-seven.vercel.app/pharmacy

โค้ด: https://github.com/piyawatn-alt/chemistry-lab-simulator

## สิ่งที่ผลงานนี้แสดงได้

- เชื่อมโครงสร้างโมเลกุลและหมู่ฟังก์ชันกับสมบัติทางเคมี โดยใช้แอสไพรินและพาราเซตามอลเป็นตัวอย่าง
- ใช้กรด–เบสและสมดุลอธิบายสัดส่วนรูปไอออน พร้อมระบุขอบเขตของการประมาณ
- แยกการละลายออกจากการดูดซึมและประสิทธิผลของยา
- ออกแบบสื่อโต้ตอบที่เปลี่ยนตัวแปรและตรวจตัวเลขได้ ส่งออกข้อมูลเพื่อวิเคราะห์ต่อ
- ฝึกการคาดการณ์ การสังเกต การอธิบาย และการระบุข้อจำกัดจากสิ่งที่ลงมือศึกษาจริง
- พัฒนาซอฟต์แวร์โดยมีการทดสอบสมการ โครงสร้าง และการใช้งาน พร้อมแหล่งอ้างอิงและบันทึกการแก้ข้อมูล

## หลักฐานที่ควรเก็บเองก่อนเลือกใส่พอร์ต

1. เปิด `/pharmacy` และอ่านโครงสร้างสารยาสองตัว แล้วเลือกประเด็นที่ตนเองสนใจ
2. ตั้งสมมติฐานก่อนเลื่อนตัวแปรใน `/tools/ionization` เช่น แนวโน้มกรดอ่อนกับเบสอ่อนที่ pH เดียวกัน
3. เปลี่ยนตัวแปรทีละอย่าง กดบันทึกอย่างน้อยสองเงื่อนไขที่ต้องการเปรียบเทียบ และส่งออก CSV ถ้าจะวิเคราะห์กราฟต่อ
4. เขียนบันทึกที่ `/journal` ระบุสิ่งที่เห็น ตัวเลข เหตุผล และสิ่งที่แบบจำลองยังบอกไม่ได้ ใช้แหล่งข้อมูลที่ได้อ่านจริง
5. กรอกชื่อ เป้าหมาย บทบาทที่ทำจริง และเครื่องมือ/ความช่วยเหลือที่ใช้ รวมถึง AI หากใช้ช่วยพัฒนา
6. ส่งออก Markdown หรือพิมพ์เป็น PDF เก็บ JSON สำรองไว้ด้วย ไฟล์ JSON นำเข้ารวมกับสมุดในอุปกรณ์อื่นได้
7. เลือกภาพหน้าจอที่อ่านออกเพียง 2–3 ภาพ และบันทึกการปรับปรุงที่ตนเองอธิบายขั้นตอนกับเหตุผลได้

บันทึกส่วนบุคคลในเว็บเริ่มต้นว่าง ไม่มีชั่วโมงเรียน คะแนน หรือผลการทดลองในห้องปฏิบัติการที่สร้างขึ้นล่วงหน้า จำนวนบันทึกแสดงเฉพาะรายการที่กดเก็บหรือเขียนเอง ข้อมูลในไฟล์ที่นำเข้าเป็นข้อมูลที่ผู้ใช้จัดเตรียม ไม่ใช่หลักฐานรับรองจากบุคคลภายนอก

## ตัวอย่างแผนศึกษาเพื่อใช้ตรวจความเข้าใจ

ตารางนี้เป็น **ผลคาดการณ์จากแบบจำลองทางทฤษฎี** สำหรับวางแผนศึกษา ไม่ใช่บันทึกว่าผู้จัดทำได้ทำกิจกรรมแล้ว

กำหนด pKa = 4.5 โดยกรณีเบสหมายถึง pKa ของคู่กรด BH⁺:

| pH | ไอออนของกรดอ่อน | S/S₀ ของกรดอ่อน | ไอออนของเบสอ่อน | S/S₀ ของเบสอ่อน |
| --- | --- | --- | --- | --- |
| 3.5 | 9.09% | 1.10 | 90.91% | 11.00 |
| 4.5 | 50.00% | 2.00 | 50.00% | 2.00 |
| 5.5 | 90.91% | 11.00 | 9.09% | 1.10 |

เหตุผลที่ควรอธิบายได้: สมดุล HA ⇌ H⁺ + A⁻ กับ BH⁺ ⇌ B + H⁺ ให้แนวโน้มสัดส่วนไอออนตรงข้ามกัน ส่วน S/S₀ = 1 + อัตราส่วนไอออนต่อรูปเป็นกลาง มาจากสมดุลการละลายเมื่อมีของแข็งรูปเป็นกลางเหลือเกินและตรึง pH จากภายนอก ไม่ได้ใช้ได้กับสารทุกชนิดหรือทุกสภาวะ

## โครงร่างคำอธิบายผลงาน 1 หน้า

กรอกแต่ละช่องจากสิ่งที่ทำจริง:

- **แรงจูงใจส่วนตัว:** ประเด็นที่เรียนแล้วไม่เข้าใจ หรือสิ่งที่อยากเชื่อมกับเภสัชศาสตร์
- **เป้าหมาย:** ปัญหาการเรียนรู้ที่โครงงานต้องการช่วย และกลุ่มผู้ใช้ที่ตั้งใจออกแบบให้
- **บทบาทของฉัน:** แยกแนวคิด การออกแบบ การเลือกเนื้อหา การตรวจข้อมูล การทดสอบ และโค้ดที่พัฒนาหรือแก้ไขเอง
- **เครื่องมือและความช่วยเหลือ:** ระบุเทคโนโลยี ผู้ช่วย หรือ AI ที่ใช้ พร้อมสิ่งที่ตรวจสอบและรับผิดชอบด้วยตนเอง
- **กระบวนการ:** หนึ่งตัวอย่างของการพบปัญหา → ตรวจหลักฐาน → แก้ → ทดสอบผล
- **ผลที่มีหลักฐาน:** ผลจำลอง บันทึกที่เขียนเอง ไฟล์ข้อมูล ภาพหน้าจอ และการเปลี่ยนแปลงใน Git ที่ตนเองอธิบายได้
- **สิ่งที่เรียนรู้:** ความเข้าใจทางเคมีที่เปลี่ยนไป และเหตุผลที่ทำให้สนใจศึกษาด้านเภสัชศาสตร์ต่อ
- **ข้อจำกัดและการพัฒนาต่อ:** สมมติฐานของแบบจำลอง แหล่งอ้างอิงที่ยังต้องตรวจเพิ่ม และวิธีเก็บข้อเสนอแนะจากผู้ใช้จริง

ตัวเว็บหรือกราฟเพียงอย่างเดียวไม่แสดงว่าผู้จัดทำเข้าใจทุกเรื่อง การเลือกหลักฐานที่อธิบายได้ด้วยคำของตนเองช่วยให้ผลงานมีน้ำหนักมากขึ้น ส่วนรูปแบบและจำนวนหน้าต้องปรับตามประกาศรับสมัครของแต่ละโครงการ

## ประเด็นทางวิทยาศาสตร์สำหรับทบทวนก่อนเล่าโครงงาน

- ความหมายของ pKa และความต่างระหว่าง pKa ของ BH⁺ กับ pKb ของ B
- เหตุผลที่ pH = pKa ให้รูปสองชนิดเท่ากันในแบบจำลองหนึ่งตำแหน่งแตกตัว
- ความแตกต่างระหว่างสัดส่วนไอออน สภาพละลายได้ อัตราการละลาย และการดูดซึม
- เหตุผลที่ pH เพียงตัวเดียวบอกตำแหน่งดูดซึมที่ดีที่สุดของยาไม่ได้
- การจำแนกเอสเทอร์/คาร์บอกซิลในแอสไพริน และเอไมด์/ฟีนอลในพาราเซตามอล
- ความหมายของการตรวจด้วย RDKit เทียบกับการยืนยันสมบัติจริงด้วยข้อมูลทดลอง
- ขอบเขตของการทดสอบโปรแกรมและข้อจำกัดการเข้าถึงเอกสารอ้างอิงสดตามบันทึกตรวจเนื้อหา

การนำเสนอนี้เป็นโครงงานพัฒนาเครื่องมือเพื่อการเรียนรู้ ไม่ใช่การค้นพบยาหรือทฤษฎีกรด–เบสใหม่ และไม่มีข้อมูลทดลองในคนหรือคำแนะนำขนาดยา
